# My AI Arcade — Нейронный Рубеж

Космический шутер-рогалик в браузере. Чистые HTML, CSS и JavaScript: без сборки и без зависимостей.

## Как запустить

Откройте `index.html` в браузере или поднимите любой статический сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

Игра работает и на GitHub Pages: файл `.nojekyll` уже в репозитории.

## Что внутри

- **Кампания:** 6 секторов, в каждом свои волны врагов и босс с несколькими фазами.
- **Бесконечный режим:** волны растущей сложности, мини-боссы и боссы по кругу.
- **Враги:** больше десятка типов, у каждого свои траектории и узоры стрельбы.
- **Оружие и бонусы:** пять типов оружия с уровнями прокачки, щит, бомбы, дроны, магнит и овердрайв.
- **Перки:** после боссов и волн можно выбрать одно из трёх улучшений на забег (выбор можно перебросить).
- **Ангар:** 4 корабля и вечные улучшения за кристаллы.
- **Награды:** достижения, таблица рекордов и сохранение в `localStorage`.
- **Эффекты:** частицы, тряска экрана, замедление времени. Звук и музыка генерируются через WebAudio.

## Управление

| Действие | Клавиатура | Сенсорный экран |
|---|---|---|
| Движение | Стрелки / WASD | Вести пальцем |
| Стрельба | Автоматически | Автоматически |
| Бомба | Пробел / X | Кнопка «Бомба» |
| Рывок | Shift / C | Кнопка «Рывок» или двойной тап |
| Точный режим | Z (зажать) | — |
| Пауза | Esc / P | Кнопка паузы |
| Звук вкл/выкл | M | Настройки |

## Структура

```
index.html
css/        стили интерфейса, HUD и меню
js/         ядро: утилиты, сохранения, звук, ввод, частицы, фон, директор волн, игра
js/data/    корабли, оружие, бонусы, перки, уровни, боссы, достижения
js/entities/ игрок, враги, боссы, пули, бонусы, дроны
js/ui/      HUD, меню, уведомления
```
